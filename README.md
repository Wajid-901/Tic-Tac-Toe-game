 🎮 Tic Tac Toe: The Unbeatable Edition

A modern, responsive implementation of the classic Tic Tac Toe game built with HTML, CSS, and vanilla JavaScript.  
Play against a friend or challenge an unbeatable AI opponent powered by the Minimax algorithm.

---

 ✨ Features

- 🎯 Dual Mode — Play Player vs Player (PvP) or Player vs Computer (PvAI).  
- 🧠 Unbeatable AI — The AI uses the Minimax algorithm to guarantee optimal moves.  
- 💎 Modern UI — Clean, minimalist, and fully responsive card-based layout.  
- 🧩 Score Tracking — Persistent counters for X Wins, O Wins, and Draws.  
- 🔄 Symbol Selection — Choose between X or O when playing against AI.

 🧠 How the AI Works (Minimax)

The Minimax algorithm enables the AI to analyze all possible moves and outcomes to ensure it never loses.

AI Decision Process:
1. 🏆 Win Check: Takes the winning move if available.  
2. 🚫 Block Check: Blocks the player's immediate win.  
3. 🔍 Optimal Search: Recursively evaluates all future moves to pick the best long-term outcome — ensuring a win or draw every time.
